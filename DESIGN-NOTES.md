# Orbiwest Professional Website v2

This version intentionally removes the previous oversized serif headline, giant hero logo, orbit decoration and demo-style icon treatment.

## Visual direction
- Enterprise/MSP rather than startup-template styling
- Inter body typography + Manrope display typography
- Approved Orbiwest navy/blue/gold colors used with restraint
- Eagle/globe emblem limited to header/footer branding
- No invented metrics, testimonials, certifications or customer counts
- Hero visual is an abstract operations framework, not a cartoon illustration
- Consistent alignment on a 1240px content grid
- Responsive at desktop, tablet and mobile widths
