# Orbiwest Technologies — Professional Web Design v3

This version intentionally avoids:
- oversized decorative logos
- transparent/matted emblem cutouts
- faux dashboards and invented metrics
- fantasy/serif display typography
- letter-in-a-box service icons
- excessive gradients, glows or animation
- marketing claims that are not supported by evidence

## Logo treatment
The eagle/globe emblem is used on its original white field in the header. This preserves its native shadow/edge treatment and avoids the "cut out of another image" look. The footer uses text branding rather than forcing the full-color emblem onto a dark background.

## Typography
System sans-serif stack only. No external font dependency.

## Brand colors
- Metallic Navy: #0B2E5F
- Royal Blue: #165EAD
- Champagne Gold: #C9A24B
- Brushed Silver: #C7CDD3
- Deep Navy: #061A33

Gold is used only as an accent, not as a dominant UI color.

## Design principles
- restrained enterprise hierarchy
- consistent 1220px content grid
- readable line lengths
- generous whitespace
- honest capability language
- responsive layout
- accessible focus states
- reduced-motion support
