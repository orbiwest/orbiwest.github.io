Network Troubleshooting Framework

A disciplined way to narrow connectivity problems without random changes.

Scope the problem

Determine whether the issue affects one device, one VLAN, one AP, one site or the whole environment.

Validate layers

Check link, addressing, gateway, DNS, routing, policy and application reachability in order.

Change carefully

Avoid making several unrelated configuration changes at once.

Document the resolution

Record the actual cause and fix so the same issue is faster to handle next time.

This resource is general operational guidance, not a substitute for environment-specific assessment or contractual requirements.
