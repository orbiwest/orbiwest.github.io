# ORBIWEST TECHNOLOGIES — ULTIMATE WEBSITE PACKAGE 2026

This is the GitHub Pages production package.

## Deploy
Delete the old website files from the `main` branch of:
`orbiwest/orbiwest.github.io`

Then upload the CONTENTS of this folder to the repository root.

The repository root must directly contain:
- index.html
- CNAME
- assets/
- robots.txt
- sitemap.xml

Do not upload the outer folder itself.

## No build step
This is a static HTML/CSS/JavaScript website. GitHub Pages can serve it directly.
