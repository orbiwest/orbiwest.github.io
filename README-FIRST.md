# Orbiwest Technologies — Premium Natural Website 2026

This package follows the final approved navy / brushed-gold Orbiwest brand direction.

## Important brand decisions
- The eagle/globe emblem is isolated and padded so the orbital ring never clips.
- ORBIWEST TECHNOLOGIES is rendered as real web text beside the emblem.
- The wordmark uses restrained metallic gradients; the rest of the interface remains calm and readable.
- No fake statistics, testimonials, client logos, phone numbers or vendor-partner claims are included.

## Browser-only GitHub deployment
1. Extract this ZIP.
2. Open https://github.dev/orbiwest/orbiwest.github.io
3. Confirm branch `main`.
4. Delete all old repository contents. Do NOT commit yet.
5. Drag EVERYTHING INSIDE this extracted folder into the empty repository root.
6. Open Source Control.
7. Commit message: `Deploy premium natural Orbiwest website`
8. Click Commit & Push.
9. Check GitHub Actions for a successful Pages deployment.
10. Open https://orbiwest.com/?v=20261105 once and then hard refresh https://orbiwest.com/

Do not upload the outer package folder itself.
