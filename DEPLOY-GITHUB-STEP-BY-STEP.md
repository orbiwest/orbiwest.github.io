# Browser-only GitHub deployment

1. Download and extract this ZIP.
2. Open `https://github.dev/orbiwest/orbiwest.github.io`.
3. Confirm the branch at the bottom-left is `main`.
4. In Explorer, select all existing repository contents and delete them.
5. Do NOT commit yet.
6. In Windows File Explorer, open this extracted package.
7. Select everything INSIDE this folder.
8. Drag those files into the empty repository Explorer in github.dev.
9. Open Source Control.
10. Use commit message:
   `Deploy ultimate Orbiwest professional website`
11. Click **Commit & Push**.
12. Open `https://github.com/orbiwest/orbiwest.github.io/actions`.
13. Confirm the Pages deployment finishes successfully.
14. Open `https://orbiwest.com` and press `Ctrl + Shift + R`.

Git commit history still provides a recovery path even if you do not create a separate backup branch.
