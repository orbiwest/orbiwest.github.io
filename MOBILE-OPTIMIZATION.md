# Orbiwest Mobile Optimization

Desktop branding/layout is intentionally preserved.

Mobile improvements:
- 66px sticky header and compact logo
- large 46px hamburger target
- full-width scrollable mobile menu
- Escape/outside-tap/menu-link close behavior
- mobile hero image asset for faster loading
- mobile hero image shortened to preserve first-screen content
- stacked, full-width hero CTAs
- compact 2x2 hero benefit layout
- touch-friendly service/catalog links
- phone-specific typography and section spacing
- one-column long-form service content
- mobile-safe tables and long text
- cleaner footer
- fixed two-button quick action bar: Talk to Orbiwest / Request Support
- safe-area support for modern phones
- reduced-motion support
- 360px narrow-phone fallback

No separate mobile site is required.
