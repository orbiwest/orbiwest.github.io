# Orbiwest Technologies — Web Brand Implementation

## Primary emblem
The primary website emblem is:
`assets/orbiwest-20261105/img/orbiwest-emblem-master-20261105.png`

It is a true transparent image with an additional transparent safety margin around all visible artwork.
Do not crop the file tighter in CSS or image editors.

## Header wordmark
The website deliberately does NOT bake the company name into the logo image.

Instead:
- Eagle/globe = transparent image
- ORBIWEST = live HTML/CSS text
- TECHNOLOGIES = live HTML/CSS text

Benefits:
- no square image background
- no clipping of the orbital ring
- sharper text at every screen density
- easier responsive sizing
- better accessibility
- easier future typography refinement

## Brand behavior
The eagle/globe is a premium identifier, not decorative wallpaper.
It appears in:
- navigation/header
- footer
- favicon / application icon
- social sharing image

It does NOT appear as a giant hero illustration or repeated background decoration.

## Typography
The web interface uses the native system sans-serif stack for predictable rendering and fast loading.
The company wordmark is styled separately from interface text.
