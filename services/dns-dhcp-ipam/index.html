Network Services

DNS, DHCP & IP Address Management

Keep foundational network services accurate, redundant and documented across sites and cloud environments.

Work we take on

  • Windows DNS / DHCP
  • Active Directory-integrated DNS
  • DHCP scopes / reservations / options
  • IP address planning
  • Cloud DNS and private zones
  • Infoblox / BlueCat when included in the engagement
  • DNS filtering integration
  • Split DNS / conditional forwarding
  • Redundancy and failover

When this deserves attention

  • Addressing has grown without documentation
  • DNS issues look like application outages
  • Multiple sites use overlapping or inconsistent subnets
  • Cloud and on-prem name resolution must work together

How we work through it

We start by understanding how traffic actually moves through the environment. That helps separate a design problem from a configuration problem before changes are made.

We also leave the customer with the information needed to understand the network. That can include diagrams, addressing, VLANs, important dependencies, configuration backups and operating notes, depending on the platform and engagement.

Ways to work with us

  • Assessment
  • Architecture / design
  • Migration / implementation
  • Troubleshooting
  • Managed / co-managed operations
