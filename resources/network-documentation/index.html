Network Documentation

What to record so troubleshooting and change work depend less on memory.

Addressing

Record subnets, gateways, DHCP scopes, static reservations and important network services.

Segmentation

Document VLAN IDs, purpose, tagging expectations and inter-VLAN policy.

Infrastructure

Record switches, firewalls, access points, uplinks and management addresses.

Access

Keep credential-handling procedures secure—not in public documentation.
