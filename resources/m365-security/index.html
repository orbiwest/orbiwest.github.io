Microsoft 365 Security

Identity, MFA, admin access and tenant hygiene to review regularly.

MFA

Require strong authentication for users and especially privileged accounts.

Admin access

Separate privileged administration from everyday activity where practical.

Access review

Remove stale users, unnecessary admin roles and old third-party access.

Recovery

Make sure account recovery, retention and backup expectations are understood.
