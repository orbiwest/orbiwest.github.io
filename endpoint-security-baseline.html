Endpoint Security Baseline

A defensible endpoint baseline starts with a few controls done consistently.

On this page1. Patch management2. Endpoint protection3. Least privilege4. Encryption5. Recovery

1. Patch management

Keep operating systems and supported applications current. Define an owner, maintenance cadence and exception process.

2. Endpoint protection

Use centrally managed endpoint security where practical and verify that protection is active, updating and reporting.

3. Least privilege

Avoid routine local-administrator use. Separate administrative actions from daily user activity.

4. Encryption

Use full-disk encryption on portable and business-critical endpoints where supported.

5. Recovery

Confirm that important data is backed up and that recovery instructions exist before an incident.

This guide is general operational guidance, not legal, compliance or vendor-specific professional advice. Adapt controls to your environment and requirements.
