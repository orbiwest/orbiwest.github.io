# Deploy Orbiwest Premium MSP / MSSP Remodel

1. Extract `orbiwest_premium_msp_mssp.zip`.
2. Open `https://github.dev/orbiwest/orbiwest.github.io`.
3. Confirm branch `main`.
4. Delete the existing website contents.
5. Do not commit the deletion separately.
6. Drag everything INSIDE the extracted package into the repository root.
7. Commit: `Deploy premium Orbiwest MSP MSSP website`
8. Push to `main`.
9. Confirm GitHub Pages completes successfully.
10. If Cloudflare proxies the domain, purge the cache once.
11. Open `https://orbiwest.com/?premium=20261106` and then hard refresh the normal site.

Do not mix files from older Orbiwest packages.
