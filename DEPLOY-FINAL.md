# Deploy Orbiwest Complete Website

1. Extract `orbiwest_complete_final.zip`.
2. Open `https://github.dev/orbiwest/orbiwest.github.io`.
3. Confirm branch `main`.
4. Delete the current website contents.
5. Do not commit the deletion separately.
6. Drag EVERYTHING INSIDE the extracted package into the repository root.
7. Commit:
   `Deploy complete Orbiwest MSP AI smart infrastructure website`
8. Push to `main`.
9. Confirm GitHub Pages deployment succeeds.
10. If Cloudflare proxies orbiwest.com, purge cache once.
11. Open `https://orbiwest.com/?complete=20261106`.
12. Then hard-refresh the normal site with `Ctrl + Shift + R`.

Do not mix this package with older Orbiwest website ZIPs.
