# Deploy Orbiwest Customer Control Final

1. Extract `orbiwest_customer_control_final.zip`.
2. Open `https://github.dev/orbiwest/orbiwest.github.io`.
3. Confirm branch `main`.
4. Delete the current website files and folders.
5. Do not commit the deletion separately.
6. Drag everything INSIDE this package into the repository root.
7. Commit: `Deploy Orbiwest customer control website`
8. Push to `main`.
9. Confirm GitHub Pages succeeds.
10. If Cloudflare proxies the domain, purge cache once.
11. Open `https://orbiwest.com/?control=20261106` and hard refresh the normal site.

Do not mix files from earlier website packages.
