# Deploy Orbiwest Large MSP and MSSP Final

1. Extract `orbiwest_large_msp_mssp_final.zip`.
2. Open `https://github.dev/orbiwest/orbiwest.github.io`.
3. Confirm branch `main`.
4. Delete the current website contents.
5. Do not commit the deletion separately.
6. Drag everything INSIDE this package into the repository root.
7. Commit: `Deploy large Orbiwest MSP MSSP website`
8. Push to `main`.
9. Confirm GitHub Pages succeeds.
10. Purge Cloudflare cache once if Cloudflare is proxying the domain.
11. Open `https://orbiwest.com/?large=20261106` and hard refresh the normal site.

Do not mix files from older website packages.
