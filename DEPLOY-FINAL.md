# Deploy the final audited Orbiwest website

1. Extract `orbiwest_final_audited.zip`.
2. Open `https://github.dev/orbiwest/orbiwest.github.io`.
3. Confirm branch `main`.
4. Delete the old website files/folders, but DO NOT commit the deletion separately.
5. Drag EVERYTHING INSIDE the extracted package into the repository root.
6. Commit: `Deploy final audited Orbiwest website`
7. Push to `main`.
8. Confirm GitHub Pages succeeds.
9. If Cloudflare proxies orbiwest.com, purge cache once.
10. Open `https://orbiwest.com/?audit=20261106` then hard-refresh the normal site.

Do not mix this package with older Orbiwest ZIPs.
