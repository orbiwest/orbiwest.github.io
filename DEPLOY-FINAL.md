1. Extract `orbiwest_restored_audited_final.zip`.
2. Open `https://github.dev/orbiwest/orbiwest.github.io`.
3. Confirm branch `main`.
4. Delete the existing website contents, but do not commit the deletion separately.
5. Drag everything INSIDE this extracted package into the repository root.
6. Commit: `Deploy restored audited Orbiwest website`
7. Push to `main`.
8. Confirm GitHub Pages succeeds.
9. If Cloudflare proxies the site, purge cache once.
10. Open `https://orbiwest.com/?restored=20261106` and then hard refresh the normal site.

Do not mix files from older Orbiwest packages.
