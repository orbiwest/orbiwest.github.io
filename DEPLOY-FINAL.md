# Deploy Orbiwest Content Cohesion Final

1. Extract `orbiwest_content_cohesion_final.zip`.
2. Open `https://github.dev/orbiwest/orbiwest.github.io`.
3. Confirm branch `main`.
4. Delete the current website contents but do not commit the deletion separately.
5. Drag everything INSIDE the extracted package into the repository root.
6. Commit: `Deploy Orbiwest content cohesion final`
7. Push to `main`.
8. Confirm GitHub Pages completes successfully.
9. If Cloudflare proxies the domain, purge its cache once.
10. Open `https://orbiwest.com/?cohesion=20261106` and hard refresh the normal site.

Do not mix files from earlier Orbiwest packages.
