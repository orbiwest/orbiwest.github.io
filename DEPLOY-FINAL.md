# Deploy Orbiwest Customer-Ready Final

1. Extract `orbiwest_customer_ready_final.zip`.
2. Open `https://github.dev/orbiwest/orbiwest.github.io`.
3. Confirm branch `main`.
4. Delete the current website files/folders, but do NOT commit the deletion separately.
5. Drag everything INSIDE this extracted package into the repository root.
6. Commit: `Deploy customer-ready Orbiwest website`
7. Push to `main`.
8. Confirm GitHub Pages succeeds.
9. If Cloudflare proxies orbiwest.com, purge cache once.
10. Open `https://orbiwest.com/?customerready=20261106` and then hard-refresh the normal site.

Do not mix this package with earlier Orbiwest ZIP files.
