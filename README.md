# Orbiwest Technologies Professional Website v3

Static production website for GitHub Pages / Cloudflare Pages.

## Deploy
Upload the CONTENTS of this folder to the root of:
`orbiwest/orbiwest.github.io`

Required root items include:
- index.html
- CNAME
- assets/
- robots.txt
- sitemap.xml

No build step is required.

## Important
This package replaces the previous Orbiwest site. It is intentionally designed to look restrained and professional rather than logo-heavy or illustration-heavy.
